# CampusConnect — Frontend Client

React + Vite frontend application for the CampusConnect campus collaboration & networking platform.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
The application will launch at `http://localhost:5173`.

### 3. Build for Production
```bash
npm run build
```
Production assets are generated in the `dist/` directory.

---

## 🛠️ Tech Stack & Libraries
- **React 18** with Functional Components & Hooks
- **Vite** for fast HMR and bundling
- **React Router v6** for client-side routing & auth route guards
- **Tailwind CSS** for layout and utility styling
- **Axios** with global interceptors for authenticated API requests
- **Lucide React** for UI icons
- **Recharts** for interactive platform analytics charts
